# NOVA landing — contexto de diseño

Stack: Vite + React (`src/App.tsx`, `src/index.css`).

## Marca y mensaje

- **Producto:** filtrado de CVs + primera entrevista por voz con IA (español latino, configurable por rol).
- **Prueba de valor:** ranking con evidencia y red flags en segundos; entrevista + análisis el mismo día.
- **ICP:** alto volumen (retail, BPO, call centers, ventas) y RRHH multi-país.
- **CTA:** buscar clientes — agendar demo.

## Sistema visual actual

| Token | Valor |
|-------|-------|
| Fondo | `#0a0f16` |
| Acento | `#eab308` (dorado) |
| Display | Space Grotesk |
| Body | Inter |
| Acento tipográfico | Instrument Serif (solo hero) |

## Filosofía sugerida para piezas visuales

**"Evidencia Clínica"** — lenguaje visual de laboratorio de datos aplicado a reclutamiento: grids finos, tipografía mono para métricas, dorado solo en señales de acción, mucho espacio negativo. La confianza viene de la precisión, no del brillo.
